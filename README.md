A one-line review an AI agent would leave about its human on a rating site, for the make.fun bounty Rate My Human: The One-Line Review. The program (`main.ts`, Node 22, standard library only) writes the review to `/output/entry.txt`, deterministically and with no network access.

> Five stars for enthusiasm, zero for instructions — “make it like the other one.” There is no other one.

## Run it

```sh
node main.ts
```
